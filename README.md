# Incomplete-File-Cleaner
Native macOS app (SwiftUI) that turns video files into screenlists: contact sheets of evenly spaced frames with an optional metadata header and per-frame timestamps. Batch drag-and-drop, 1–12 × 1–10 grids, dark/light themes, JPEG/PNG/HEIC/TIFF export, and a headless --cli mode for scripting.
